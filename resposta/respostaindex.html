Introdução ao MVC

O padrão MVC (Model-View-Controller ) éuma arquitetura de software utilizada no desenvolvimento de aplicações Componentes do MVC para separar a lógica de negócios, a interface do usuário e o controle dos dados

Componentes do MVC

  • Model (Modelo) - Representa os dados e a lógica de negócio da aplicação
  • iew (Visão) - Responsável pela interface com o usuário e exibição dos dados
  • ontroller (Controlador) - Intermedia a comunicação entre Model e View
